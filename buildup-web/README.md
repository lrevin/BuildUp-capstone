# Build Up 웹 대시보드 (buildup-web)

Build Up 건설 현장 진행 보고 시스템의 **본사·현장 관리자용 웹 대시보드**입니다.
모바일 앱(BuildUpApp)으로 현장에서 올린 진행 보고·사진·자재 요청을 PC 화면에서 한눈에 보고,
보고를 검토(승인 / 보완 요청)하고 자재 요청을 처리하며 작업일보 엑셀을 내려받을 수 있습니다.

- 기술: Vite + React + TypeScript, react-router, axios, Recharts
- 서버: `buildup-server`(Spring Boot) REST API를 그대로 사용합니다.
- 디자인: 모바일 앱과 같은 색(남색 + 노란색 강조, 바탕 `#F2F4F7`)과 Pretendard 글꼴

## 실행 방법

사전 준비: Node.js 20 이상, `buildup-server`가 `http://127.0.0.1:8080`에서 실행 중이어야 합니다.

```bash
cd buildup-web
npm install        # 의존성 설치(처음 한 번)
npm run dev        # 개발 서버 → http://localhost:5173
npm run build      # 배포용 빌드 → dist/ (타입 검사 포함)
npm run preview    # 빌드 결과 미리 보기
```

## 환경 변수

| 이름 | 설명 | 기본값 |
| --- | --- | --- |
| `VITE_API_BASE` | 서버 API 주소(`/api`까지) | `http://127.0.0.1:8080/api` |

다른 서버를 쓰려면 `buildup-web/.env.local` 파일을 만들고 아래처럼 적습니다.

```
VITE_API_BASE=http://192.168.0.10:8080/api
```

## 체험용 계정 (비밀번호 모두 `1234`)

| 계정 | 이름 | 역할 |
| --- | --- | --- |
| `hq@buildup.kr` | 정본사 | 본사 관계자(한빛건설 본사) — 연결된 현장 2곳 |
| `admin@buildup.kr` | 이영호 | 현장 관리자 — 직접 관리하는 현장 2곳 |
| `park@buildup.kr` | 박철근 | 현장 관리자(최고 책임자) — 본인 현장 |

작업자 계정(`worker@buildup.kr` 등)은 웹 대시보드를 쓸 수 없고
"본사 관계자 또는 현장 관리자 계정으로 로그인해 주세요" 안내가 나옵니다.
로그인 화면의 체험용 계정 버튼을 누르면 바로 로그인됩니다.

## 화면 구성

1. **로그인** (`/login`)
   - 이메일·비밀번호 로그인, 체험용 계정 빠른 로그인
   - 로그인 상태는 브라우저에 저장되어 새로고침해도 유지(`/api/auth/me`로 복구), 토큰이 만료되면(401) 로그인 화면으로 이동
2. **대시보드** (`/`)
   - 핵심 지표: 관리 현장 수, 평균 진행률, 지연 현장 수, 검토 대기 보고, 승인 대기 자재
   - 현장 카드: 현장명·주소, 전체 진행률 막대와 오늘 기준 계획 진행률 표시선(노란 선), 지연이면 빨간 "지연 N%p" 배지, 검토 대기·자재 대기 배지. 지연이 큰 현장부터 정렬
   - 오른쪽 "새로 올라온 보고": 최신 보고와 검토 상태(검토 대기 파랑 / 승인 초록 / 보완 요청 주황), 확인이 필요한 보고는 ⚠ 표시. 누르면 보고 상세
   - 본사 관계자는 연결된 모든 현장, 현장 관리자는 직접 관리하는 현장(`isOwner`)만 보입니다.
3. **보고 상세 (팝업)**
   - 작성자·제출 시각·공정·진행률(이전 → 이후), 메모, 작업일보(날씨·인원·장비)
   - 사진 모음("촬영 M/D HH:mm" 표시, 누르면 크게 보기), 첨부 파일, 제출 위치(구글 지도 링크)
   - 오래된 사진·현장 밖 제출 등 의심 항목 경고
   - 검토: 상태·검토자·의견 표시, 권한이 있으면 **승인** 또는 **보완 요청**(사유 입력 + 자주 쓰는 사유 버튼)
4. **현장 상세** (`/sites/:id`)
   - 전체 진행률, 오늘 기준 계획, 지연/앞섬 상태
   - 공정별 진행률 가로 막대 차트 + 계획 진행률 표시선
   - 전체 진행률 추이 선 차트: 보고 이력으로 날짜별 누적 진행률을 공정 비중으로 다시 계산, 계획 진행률과 비교
   - 사진 타임라인: 날짜별(최신순) 사진 썸네일과 공정명
   - 진행 보고 표: 공정별 필터, 검토 상태, "더 보기"로 이어서 불러오기
   - 자재 요청 목록: 권한이 있으면 승인 / 반려(사유 입력)
   - 작업일보 엑셀 내려받기: 최근 7일 / 이번 달 / 최근 30일

## 폴더 구조

```
src/
  api.ts                 서버 API 호출(토큰 첨부, 401 처리, 엑셀 내려받기)
  auth.tsx               로그인 상태 관리
  types.ts               API 데이터 타입(모바일 앱 types.ts 기반)
  utils/plan.ts          계획 진행률·지연 계산(모바일 앱과 같은 규칙)
  utils/format.ts        날짜·숫자 표시
  components/            상단바, 공통 UI, 보고 상세 팝업
  charts/                공정별 진행률, 진행률 추이 차트
  pages/                 로그인, 대시보드, 현장 상세
  styles.css             전체 스타일
```
